# Ar — Assinatura do Ar

Startup fictícia de humor: você paga mensalmente para receber uma experiência exclusiva de… respirar.

A página mostra uma esfera que "respira" em ciclos de 4 segundos. Depois de 5 respirações gratuitas, aparece um paywall pedindo para assinar um plano.

## Planos

| Plano | Preço | O que inclui |
|---|---|---|
| Ar Comum | R$ 9/mês | 5 respirações por sessão, com anúncios |
| Ar Premium | R$ 29/mês | Respirações ilimitadas |
| Ar Reserva | R$ 149/mês | Ar de 1998, engarrafado |

## Como rodar

Abra o arquivo `index.html` em qualquer navegador. Não precisa instalar nada.

## Tecnologias

- HTML, CSS e JavaScript puros, em um único arquivo
- Fontes: Unbounded e Familjen Grotesk (Google Fonts)
